How to view

cd physiology-app/tools/ui-preview
python3 -m http.server 8123
# open http://localhost:8123/

Or double-click any file — no build step. Each prototype has a light/dark toggle (A, B).

What to judge

  • Which feels most clinical and trustworthy to a med student / resident?
  • Is the simulator scannable in 5 seconds (MAP, CO, lactate)?
  • Does the mobile 390pt frame feel like the same product?
  • Mix-and-match is allowed — e.g. A chrome + C explainer typography.
